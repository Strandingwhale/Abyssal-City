## 顺序 1：先写 `internal/common/packet.go`

功能：

- Encode：消息 ID + protobuf 二进制 → 组装成 `[4字节长度][2字节msgId][payload]` 的包（大端）
- Decode：从字节缓冲区里不断读，切出完整包，处理半包、粘包

> 
> 提示：你需要一个缓冲区（bytes.Buffer）存还没解析完的残留字节。

写完之后，新建 `internal/common/packet_test.go` 写单元测试：自己拼多组包、半包、粘包的字节，测试 Decode 能不能正确拆出来。

## 顺序 2：`internal/common/logger.go`

封装 zap 或者标准 log 都行，简单统一日志，带时间、模块标记，方便网关打印连接、心跳、掉线日志。

> 
> 不用做复杂日志分割，够用就行。

## 顺序 3：`api/base.proto`

写 proto3，只定义 PingReq、PingResp，生成脚本写在 `scripts/gen_proto.bat`，跑通 protoc，确认能正常生成 pb.go。

> 
> 注意 go_package 别写错。

## 顺序 4：`internal/gateway` 包

两个核心文件：

1. `session.go`
Session 结构体：保存 conn、sessionId、lastPingTime（最后收到心跳的时间）
每个客户端连接对应一个 Session。
2. `server.go`
   - Start ()：监听 TCP 端口
   - 循环 Accept 新连接，为每个连接启动单独 goroutine 处理读包
   - 一个后台定时 goroutine（比如每 1s 遍历全部 session）：检查 当前时间 - lastPingTime > 超时阈值 → 关闭连接、清理 session

> 
> 读包逻辑：从 conn 循环 Read，读到的数据丢进 packet 的 buffer，调用 Decode，拿到消息。
> 如果消息 ID 是 ping，就更新 lastPingTime，构造 PingResp 打包发回去。

## 顺序 5：`cmd/gateway/main.go`

main 要薄：

1. 初始化 logger
2. 新建 gateway server 实例
3. 调用 server.Start ()，阻塞运行

## ✅ 开发里的重点提醒（避坑）

1. 并发安全：Session 集合（存所有在线玩家）读写一定要加锁 `sync.Mutex`，读包协程、定时清理协程都会访问它。
2. 字节序：包头的 uint32、uint16 必须用**大端（binary.BigEndian）**，客户端和服务端要一致。
3. 读 TCP 的时候，Read 返回 io.EOF 代表对方正常关闭，直接清理 session。
4. 心跳超时建议设 8~10s，不用太短。
5. proto.Marshal 得到 payload 之后，再交给 packet.Encode 打包；收到包先 Decode 拿到 payload，再 proto.Unmarshal。
